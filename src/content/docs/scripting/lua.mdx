---
title: Lua scripting
description: Where Lua scripts live and how Plus Engine calls their lifecycle hooks.
---

Lua is the most portable scripting path for existing Psych mods. Song scripts normally live in `mods/<mod>/data/<song>/` and global scripts in `mods/<mod>/scripts/`.

```lua title="scripts/hello.lua"
function onCreatePost()
    debugPrint('Plus Engine loaded this Lua script')
end

function onBeatHit()
    if curBeat % 4 == 0 then
        debugPrint('Measure at beat ' .. curBeat)
    end
end
```

The `dev` template currently defines `onCreate`, `onCreatePost`, `onUpdate`, `onUpdatePost`, `onBeatHit`, `onStepHit`, `onDestroy`, and gameplay-specific callbacks.
