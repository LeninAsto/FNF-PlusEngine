La documentación Lua original de Psych es una fuente de referencia. Cada entrada se comprueba por separado contra Plus Engine e indica si la verificación en runtime está completa.

- **Psych upstream** identifica la documentación original.
- **Necesita revisión** significa que se encontró código o documentación, pero aún falta completar la matriz de compatibilidad.
- **Verificada** se reserva para entradas probadas en un commit registrado de Plus.
