Plus Engine

Project overview and documentation portal

Plus Engine is based on Psych 1.0.4 and retains a modchart direction inspired by NotITG. The engine also supports hxcodec video playback from Psych mod versions 0.6.3 and 0.7.3.

This hub presents the project summary, the documentation routes for Psych and Plus, and the presentation media for the project.

Project summary

The README describes Plus Engine as a fork with Haxe root, Material Design presentation, Android support, multiple language options, and modding-friendly tooling that keeps the original engine structure intact.
