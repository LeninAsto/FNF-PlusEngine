Compatibilidad y seguridad

Los callbacks de Windows y GDI son específicos de esa plataforma. Los efectos GDI pueden ser molestos o inseguros para usuarios fotosensibles y nunca deben activarse sin consentimiento claro.

Para callbacks estándar, consulta la API Lua de Psych.
