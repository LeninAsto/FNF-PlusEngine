Cómo correr un script

Hay 6 tipos de scripts LUA que puedes usar:

  • Script de stage: Solo se ejecuta si el stage de la canción está cargado en el chart actual; debe tener el mismo nombre que el JSON del stage y estar dentro de mods/My-Mod/stages/.
  • Script de tipo de nota: Solo se ejecuta si el tipo de nota se está usando en el chart actual; debe estar dentro mods/My-Mod/custom_notetypes/.
  • Script de evento: Solo se ejecuta si ese evento se usa en el chart; debe estar dentro mods/My-Mod/custom_events/.
  • Script(s) de canción: Deben guardarse dentro de la carpeta del chart de la canción; solo corren en esa canción, sin importar dificultad, stage ni nada más.
  • Script de personaje: Solo se ejecuta si el personaje indicado se usa en la canción. Puedes usar las variables dadName, boyfriendName y gfName para revisar el nombre del personaje actual; debe ir en mods/My-Mod/characters/.
  • Script general: Debe ir en mods/My-Mod/scripts/, y se ejecuta en todas las canciones mientras el mod esté cargado.
