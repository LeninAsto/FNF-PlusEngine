# Plus Engine Documentation Site
This is a documentation site for Plus Engine that contains guides on using Psych/Plus API with a Material Design interface while retaining classic layout (for Psych only) and video previews of modchart NotITG.

In addition, this documentation site is also available in English and Spanish (other languages will be added soon)

# Contributing
We really need you to add missing NotITG modchart video previews and also add languages

Before contributing, make sure you have [Git](https://git-scm.com/) installed on your computer, and then get started.

```
git clone -b web-page --single-branch https://github.com/Psych-Plus-Team/FNF-PlusEngine.git
```
Run this command in your Terminal/Bash. If you already have an `FNF-PlusEngine` folder, please add your folder name after repository link.

# Formatting
When you make changes in VSCode, use Prettier extension to format the files!

You can install Prettier extension [here](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)
